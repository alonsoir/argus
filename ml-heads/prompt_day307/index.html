    Reglas de trabajo (las de siempre)

    Medir, no votar; predicción escrita antes de medir; si algo no da lo esperado, PARAR. Comandos exactos y completos, en orden, diciendo dónde se ejecuta cada uno (Mac / defender / client), con la salida redirigida a fichero + ; cat. Ficheros generados como descarga con sha256. Parcheadores que validen TODO antes de escribir NADA (sha256 de cada fichero de partida, anclas únicas, sha256 de los bloques que se borran, estado "ya aplicado", --check/--apply). git grep, nunca grep -rn . en la raíz. awk con LC_ALL=C. En el Mac, cat -vet (no cat -A). El JSON es la ley; ningún campo se lee en silencio. Compilar siempre en producción y el pipeline completo (make pipeline-build PROFILE=production, y make tools-build PROFILE=production si se tocan herramientas). Diagnósticos: grep -E ':[0-9]+:[0-9]+: (warning|error):'. Pruebas: make test-components PROFILE=production. E2E: make lab-e2e-protegidos LAB_E2E_DIA=dayNNN (formato estricto dayNNN; si el directorio del día ya existe, renombrarlo antes) o make lab-e2e (los cinco). vagrant up sin nombre solo levanta el defender: vagrant up client y después make lab-clock-step. No se mantiene código deprecado: se borra.
